Privacy

What this site stores

The sample issuer

The demo needs no signup and stores nothing about you. It is a fixed dataset built from public documents.

The pilot form

When you request a pilot we store what you enter — name, email address, organisation, role, the issuers and workflow you describe and any notes — with the time it arrived and which page of this site you came from. If you send the form again with the same email address, the same record is updated rather than a second one created. {{privacy_crm}}

We use it only to reply to you about a pilot. You are not added to a mailing list, no outreach sequence is started, and it is not sold or shared for marketing. It is kept in our database, hosted on AWS in Mumbai (ap-south-1), until you ask us to delete it.

To stop the form being flooded, each submission records a salted one-way hash of the address it came from. The hash cannot be turned back into an address, is used only to count recent submissions, and is deleted when the rate-limit window passes. Your IP address itself is not stored.
